
**Шаг 1: Обсуждение и детализация верхнеуровневой архитектуры**
На этом шаге мы обсудим общую структуру системы, которая уже реализована. Ты опишешь, что уже есть, а мы вместе детализируем, что нужно добавить. Цель — получить общую картину, которая включает существующие и будущие компоненты.

* **Твой запрос:** "Опиши текущее состояние архитектуры: какие сервисы уже реализованы, как они взаимодействуют. Давай вместе определим, какие новые сервисы нужно добавить для реализации полного функционала."

**Шаг 2: Создание диаграмм последовательности для ключевых сценариев**
Вместо одного сценария мы создадим несколько. Ты можешь выбрать самые важные. Например:
* **Сценарий 1:** Загрузка данных и запуск обучения модели.
* **Сценарий 2:** Развертывание обученной модели в виде API.
* **Сценарий 3:** Мониторинг модели в продакшене.

* **Твой запрос:** "Выбери и опиши 2-3 ключевых пользовательских сценария для нашей платформы. Нарисуй для каждого сценария диаграмму последовательности."

**Шаг 3: Проектирование ключевых сущностей**
После того как мы разберемся с логикой работы, мы перейдём к проектированию базы данных. Мы определим основные сущности (`Проект`, `Модель`, `Набор данных`, `Пользователь`) и покажем, как они связаны. Это будет основой для хранения данных в системе.

* **Твой запрос:** "Спроектируй диаграмму сущностей и связей (Entity-Relationship Diagram) для ключевых компонентов. Укажи основные атрибуты и связи между ними."

**Шаг 4: Разработка спецификаций API**
Мы опишем API для взаимодействия между нашими сервисами. Это важно для того, чтобы разные команды могли работать над разными частями проекта, не мешая друг другу.

* **Твой запрос:** "Опиши спецификацию REST API для ключевых сервисов, например, `Сервиса обучения моделей` и `Сервиса развертывания моделей`."

**Шаг 5: Описание технологий и инструментов**
На последнем шаге мы составим список конкретных технологий, которые лучше всего подходят для реализации каждого компонента. Например, какой фреймворк для бэкенда, какая база данных и т.д.

* **Твой запрос:** "Составь список рекомендуемых технологий и инструментов для каждого компонента архитектуры."
